## **1. Diagram Layout**

**Orientation:** Landscape, layered top-down flow
**Layers:** 4 major horizontal tiers

1. **Identity & Authentication Layer** (top)

   * Users, Devices, Identity Control Plane
   * Color: Red 🔴 Critical
   * STRIDE: Spoofing, Information Disclosure

2. **Authentication-State / Transition Layer** (second)

   * FSM, Transition Control Plane
   * Color: Orange 🟠 Medium
   * STRIDE: Tampering, Denial of Service

3. **Telepresence & Node Layer** (third)

   * Telepresence Orchestrator, Telepresence Pods, Service Mesh, Edge Nodes
   * Colors: Telepresence = Red 🔴 Critical, Nodes & Mesh = Orange 🟠 Medium
   * STRIDE: Elevation of Privilege, Session Hijack, Node Impersonation

4. **Audit / Mitigation Layer** (bottom)

   * Audit Service, Logs, Mitigation Feedback Loops
   * Color: Green 🟢 Low
   * STRIDE: Repudiation, Information Disclosure

**Legend Section (bottom-left)**

* Red 🔴 Critical
* Orange 🟠 Medium
* Green 🟢 Low
* Dotted arrows = Attack vectors
* Solid arrows = Mitigation / feedback

## **3. Flow and Arrows**

**Attack vectors** (dotted red/orange lines):

* User → Identity: Credential theft / spoofing
* Transition → Telepresence: FSM tampering / event suppression
* Telepresence → Nodes: Session hijack / privilege escalation
* Service Mesh → Nodes: Node impersonation

**Mitigation arrows** (solid green):

* Audit → Transition → Telepresence: Alerts, revocation, session termination
* Service Mesh → Telepresence: mTLS + CT validation
* Node → Telepresence: Device attestation

**Feedback loops**:

* Audit logs trigger SOC alerts → mitigation enforcement
* FSM ensures ephemeral CTs terminate unauthorized telepresence

## **4. Heatmap Representation**

* **Red 🔴**: Critical risk, requires immediate attention
* **Orange 🟠**: Medium risk, needs continuous monitoring
* **Green 🟢**: Low risk, passive monitoring / auditing
