\section{Stage Game}

Each period proceeds as follows:

\begin{enumerate}
    \item Nature assigns $(\SSS, \HS)$.
    \item Source chooses $r_t \in \{\Truth, \Spin, \Fabricate, \Silent\}$.
    \item Handler observes message $m_t$.
    \item Handler chooses $a_t \in \{\Act, \Probe, \Discount, \Sanction\}$.
    \item Outcome $o_t$ is realized.
    \item Beliefs are updated.
\end{enumerate}
