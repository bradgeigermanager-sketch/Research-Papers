\section{Players, Types, and Beliefs}

The source has type


\[
\SSS = (I, M, D),
\]


where $I$ is information stock, $M$ is strategic orientation, and $D$ is
desperation.

The handler has type


\[
\HS = (V, P, S_c),
\]


where $V$ is verification capacity, $P$ is institutional pressure, and
$S_c$ is sanction credibility.

Beliefs are updated from the public history using Bayes' rule.
