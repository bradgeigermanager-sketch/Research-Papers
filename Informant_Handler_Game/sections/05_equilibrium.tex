\section{Strategies and Equilibrium}

A source strategy is a mapping


\[
\sigma_S : (\SSS, h_t) \mapsto r_t.
\]



A handler strategy is a mapping


\[
\sigma_H : (\HS, h_t, m_t) \mapsto a_t.
\]



\begin{definition}[Perfect Bayesian Equilibrium]
A strategy profile $(\sigma_S^*, \sigma_H^*)$ and belief system
$\{\mu_t^*, \nu_t^*\}$ form a PBE if each player's strategy maximizes
expected discounted utility given beliefs, and beliefs are updated using
Bayes' rule wherever possible.
\end{definition}
